# sistem-informasi-data-pegawai
This is my project where I built an employee data information system for BPS Tanjungbalai City

To run this project locally, ensure you have enabled the Apache and MySQL modules in the XAMPP control panel, then copy the entire source code folder into the htdocs directory, import the provided .sql file into phpMyAdmin after creating the appropriate new database, and finally access the system through your web browser by navigating to http://localhost/your-project folder-name.
